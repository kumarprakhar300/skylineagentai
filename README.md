# Real Estate AI Assistant

Hi,

Assignment: Build a Live Real Estate AI Calling Agent

As part of the final technical interview round, you are required to build and present a live working AI calling agent for the real estate industry.

The purpose of this assignment is to evaluate your ability to independently research, learn new tools, integrate different technologies, and deliver a functional AI-based solution.

What You Need to Build

Create an AI voice-calling agent that can communicate with a prospective real estate client in:

* Hindi
* Hinglish
* Basic English, whenever required

The AI agent should behave like a real estate sales executive and have a natural conversation with the customer.

Minimum Conversation Flow

The AI agent should be able to:

1. Greet the customer and introduce itself as a real estate representative.
2. Ask whether the customer is looking to buy or invest in a property.
3. Understand basic requirements such as:
    * Preferred location
    * Property type
    * Configuration such as 2 BHK, 3 BHK, 4 BHK, plot or commercial property
    * Budget range
    * Purpose: self-use or investment
    * Expected purchase timeline
4. Answer basic questions related to a sample property project.
5. Handle simple customer interruptions or follow-up questions.
6. Collect the customer’s details and requirements.
7. End the conversation professionally.
8. Generate a basic call summary after the conversation.

Sample Project

You may create your own dummy real estate project or use a publicly available project for the demo.

The agent should know basic project information such as:

* Project name
* Location
* Available configurations
* Approximate price range
* Key amenities
* Possession timeline
* Major location advantages

Do not use confidential or unauthorized company data.

Mandatory Deliverables

You must submit:

* A live working URL or demo link
* A working phone-call demo or browser-based voice demo
* A short video recording showing the complete working flow
* Source code repository link
* A short document mentioning:
    * Tools and technologies used
    * AI model used
    * Voice or calling platform used
    * How the conversation flow was created
    * Challenges faced
    * What you would improve in the next version

The live URL should remain accessible during the interview.

Live Interview Demonstration

During the interview, you may be asked to:

* Start a fresh live conversation
* Change the customer’s property requirement
* Change the budget or preferred location
* Demonstrate a Hindi or Hinglish conversation
* Explain the system architecture
* Show where the collected lead information is stored
* Modify a small part of the conversation flow

A recorded or pre-edited demonstration alone will not be considered a complete submission. A live working demonstration is mandatory.

Important Instructions

* You may use any suitable AI tool, API, voice platform, cloud service, no-code platform or open-source technology.
* You are expected to research and learn independently.
* The solution does not need to be production-ready, but the core workflow must work.
* The conversation should feel natural and should not sound like a fixed IVR recording.
* The agent should not provide false commitments, guaranteed returns or misleading property information.
* Clearly mention which parts of the solution are functional and which are simulated.
* Copying an existing project without understanding or explaining it may result in rejection.

Evaluation Criteria

Your submission will be evaluated on:

* Whether the live demo actually works
* Hindi and Hinglish conversation quality
* Naturalness of the voice interaction
* Understanding of customer responses
* Real estate requirement qualification
* Handling of unexpected responses
* Call summary and lead-data capture
* Technical implementation and integrations
* Code quality and system structure
* Independent learning and problem-solving ability
* Ability to explain and modify the solution
